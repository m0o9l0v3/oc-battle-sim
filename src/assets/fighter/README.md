# ファイターのパーツ素材（#28）

オリジナルの 2D キャラクター「ファイターラボのマスコット」の、パーツ素材。**ベクター（SVG のパスデータ）**で持つため、画面の大きさ・解像度に依存せず、拡大しても崩れない（character-design.md §7.3）。仕様は [character-design.md](../../../docs/02-fighter/character-design.md)、[animation.md](../../../docs/02-fighter/animation.md)。

## 構成（31 点）

| ファイル         | 内容                                                                                                             | 点数 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ---- |
| `bodies.ts`      | 体型 4 種（`b1` まるっこい、`b2` かくかく、`b3` すらっと、`b4` がっしり）の、頭・胴体・腕・脚                    | 16   |
| `faces.ts`       | 顔 6 種（`f1`〜`f6`）+ 全員共通の表情 3 種（攻撃・やられ・撃墜）                                                 | 9    |
| `accessories.ts` | アクセサリー 6 種（`a1` ぼうし、`a2` ゴーグル、`a3` マフラー、`a4` リボン、`a5` ヘッドホン、`a6` つばさ）        | 6    |
| `palette.ts`     | 色 8 種（`c1`〜`c8`）。色の枠（主色・副色・差し色）の組を、数値で持つ（絵は用意しない）                          | —    |
| `compose.ts`     | パーツを重ねて SVG にする（S02 のプレビュー、素材の確認）。アニメーション（#29）の、重ね順・関節・親子関係の基準 | —    |
| `types.ts`       | 型と、座標系の規則                                                                                               | —    |

## 座標系

- ファイターの空間: **身長 100**。頭の上端 `y = 0`、足元 `y = 100`（下が正）、体の中心 `x = 0`。右向きで描く（左向きは全体を反転）。
- 各パーツの絵は、**関節を原点**としたローカル座標（animation.md §4.1）。回転・拡大縮小は関節を中心に行う。`BodyDef.at` が、親から見た関節の位置。
- 階層: `root > legB、legF、torso > armB、head（> face）、armF`。
- 重ね順（奥 → 手前）: 背中のアクセサリー → 奥の腕 → 奥の脚 → 胴体 → 手前の脚 → 頭 → 顔 → 手前の腕 → 頭・顔・首のアクセサリー（character-design.md §4.2）。
- 腕・脚は 1 つの絵を、手前・奥の両方に使う。奥は、陰影（`shade`）を重ねて暗くする。

## 色替え（色の枠）

塗りは、色の枠（`primary`、`secondary`、`accent`）と、共通の色（肌・輪郭線・目・白目・ガラス・ほお）、陰影（`shade`、`light`。半透明）に分けて指定する。**色の値は、絵の中に書かない**。`palette.ts` の組を当てて塗る。色ごとの絵は用意しない。

## 品質の規則（character-design.md §7.1）

- すべてのパーツに、一貫した輪郭線（太さ 2.2 が標準。小さな部分は 1.2〜2.8）。
- 円・四角などの基本図形そのままではなく、特徴のある形（耳、ほおのふわふわ、とがった髪、ヘルメットなど）。
- 陰影は 2 段階（暗い重ね `shade`、明るい重ね `light`）。
- 腕・脚に、関節の曲がりと、手先・足先（手のひらと親指、つま先の向きがあるくつ）。
- 全パーツで、線の太さ・陰影のつけ方・角の丸め方を統一（`stroke-linejoin: round`）。

## 独自性・権利（NFR-07。#50 の確認の入力）

- **すべて、このプロジェクトで、ゼロから描いたオリジナル**（トレース・既存の画像・フォント・素材の取り込みなし）。外部のファイルを使っていない。
- 既存のゲーム・アニメのキャラクターを連想させる意匠（特定の帽子・服・髪型・配色の組み合わせ）を、使っていない。胸の「いなずま」は、ファイターラボ（実験室）の「ひらめき」を表す、独自のマーク。
- 色 8 種は、色相が違う 6 色と、明るい・暗い各 1 色。既存作品のキャラクターの配色の組み合わせを、再現していない。
- 出所とライセンスの確認は、#50（`docs/00-overview/ip-review.md`）。

## 使い方

```ts
import { fighterSvg } from '../assets/index.ts'
const svg = fighterSvg(
  { appearance: { body: 'b1', face: 'f1', color: 'c1', accessory: null } },
  200,
)
```

画面での一覧は `ui/FighterGallery.tsx`（開発用）。
