# 吹き飛ばし（knockback.md）

- 文書ID: CMB-KNOCKBACK
- バージョン: 0.1
- 状態: 草案（係数は暫定。バランス調整は #25）
- 上位文書: [combat-system.md](./combat-system.md)
- 関連: [damage.md](./damage.md)、[stat-system.md](../02-fighter/stat-system.md)、`recovery.md`（#12）

## 1. 概要

攻撃が当たったとき、相手がどれだけ吹き飛ぶかを、蓄積ダメージと `defense` から決める式を定義する。**`defense` は、この式の中で、吹き飛ばされる量だけを変える**（受けるダメージは変えない）。

## 2. 目的

- 「ダメージ蓄積 → 吹き飛び量の増加 → 場外 → 撃墜」の、中間の段階を定める（REQ-CMB-01）。
- `defense` の違いが、吹き飛ぶ距離として、見て分かる（REQ-EXP-02）。

## 3. 吹き飛ばしの速さ

```text
launchSpeed = (KB_BASE + KB_SCALE × damage_after) × (1 − K_defense × (defense − 5))
```

| 名前 | 値 | 内容 |
|---|---|---|
| `KB_BASE` | **8 セル/秒** | 蓄積ダメージが 0 % のときの、基本の速さ |
| `KB_SCALE` | **0.15 セル/秒/%** | 蓄積ダメージ 1 % ごとに増える速さ |
| `damage_after` | — | **今のヒットのダメージを足したあとの**、相手の蓄積ダメージ（内部の小数の値。[damage.md](./damage.md) §4） |
| `K_defense` | 0.10 | 1ポイントあたり標準比 ∓10%（[stat-system.md](../02-fighter/stat-system.md) §6.2） |

- 蓄積ダメージが大きいほど、速く吹き飛ぶ。これが、撃墜につながる（REQ-CMB-01）。
- `defense` が高いほど、`(1 − K_defense × (defense − 5))` が小さくなり、吹き飛ぶ速さが下がる。
- **攻撃側の `attackPower` は、この式に入らない**（与えるダメージの量だけが変わる。ダメージが増えた結果、間接的に吹き飛ぶ速さは増えるが、`attackPower` が直接変えるのは、ダメージの量だけ）。

### 3.1 `defense` の倍率

| `defense` | 2 | 3 | 4 | **5** | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|
| 吹き飛ぶ速さの倍率 | 1.30 | 1.20 | 1.10 | **1.00** | 0.90 | 0.80 | 0.70 |

## 4. 向きと角度

| 項目 | 規則 |
|---|---|
| 向き（水平） | **攻撃してきた相手から、離れる向き**（相手の位置より、自分が右にいれば右。同じ位置のときは、攻撃した側の向きの前方） |
| 角度 | 水平から **65° 上向き**（全員・全ヒット共通） |
| 速度への分解 | `vx = launchSpeed × cos(65°) × 向き`、`vy = launchSpeed × sin(65°)`（上向きが正） |

- 角度を固定にするのは、結果の予測を単純にするため（設計原則 2）。距離は、速さだけで決まる。
- **65° にした理由（2026-10-04 に 40° から変更）:** 40° では、ステージの端で1回当たっただけで、水平に遠くへ飛ばされ、復帰できずに落下して撃墜された（復帰の見積もり。[recovery.md](./recovery.md) §7）。65° にすると、上へ多く飛び、水平のずれが小さくなるため、**ダメージが小さいうちは復帰でき、ダメージが大きいと復帰できない**、という「ダメージ蓄積 → 撃墜」の流れになる（REQ-CMB-01）。
- 地面にいる相手も、空中にいる相手も、同じ角度で飛ぶ。

## 5. やられ中（hitstun）の長さ

```text
hitstunMs = min(HITSTUN_MAX, HITSTUN_BASE + HITSTUN_SCALE × launchSpeed)
```

| 名前 | 値 |
|---|---|
| `HITSTUN_BASE` | 150 ms |
| `HITSTUN_SCALE` | 25 ms/（セル/秒） |
| `HITSTUN_MAX` | 1200 ms |

- 吹き飛ぶ速さが大きいほど、やられ中が長い。ステップ数は、`ceil(hitstunMs ÷ 16.67)`。
- やられ中は、操作できず、追加の攻撃を受けない（[combat-system.md](./combat-system.md) §7.2）。やられ中が終わると、12ステップの無敵が続く。
- やられのアニメーション（[animation.md](../02-fighter/animation.md) §5.6）は、この間、のけぞった姿勢を保つ。

## 6. 吹き飛んでいるときの動き

| 場面 | 規則 |
|---|---|
| 空中 | 重力（37.5 セル/秒²）だけが働く。空気の抵抗はない。水平の速さは、そのまま |
| 地面の上 | 水平の速さを、**摩擦で 60 セル/秒² ずつ減らす**。上向きの速さは、通常どおり |
| 壁・足場に当たる | 当たった向きの速さを 0 にする（跳ね返らない） |
| 地面に着く（やられ中） | 下向きの速さを 0 にし、水平の速さは、摩擦で減る |
| やられ中が終わったあと | 通常の動き（左右の移動、ジャンプ、攻撃）ができる。残っている速度は引き継ぐ |

- 物理の計算は、#22 で、固定のステップで行う（半陰的オイラー法を想定）。
- 復帰（ステージに戻る）の動きは、`recovery.md`（#12）。

## 7. 吹き飛ぶ距離の目安

吹き飛ぶ速さ、水平に飛ぶ距離（平らな地面から、飛び始めた高さまで戻ったとき）、やられ中の長さの目安。

| 蓄積ダメージ | `defense` 2（×1.3） | `defense` 5（標準） | `defense` 8（×0.7） |
|---|---|---|---|
| 12 %（最初の1回） | 12.7 セル/秒、3.3 セル、469 ms | 9.8 セル/秒、2.0 セル、395 ms | 6.9 セル/秒、1.0 セル、322 ms |
| 36 % | 17.4、6.2、586 | 13.4、3.7、485 | 9.4、1.8、384 |
| 60 % | 22.1、10.0、702 | 17.0、5.9、575 | 11.9、2.9、447 |
| 100 % | 29.9、18.3、898 | 23.0、10.8、725 | 16.1、5.3、552 |
| 150 % | 39.6、32.1、1141 | 30.5、19.0、912 | 21.3、9.3、684 |

- 各セルは、「速さ（セル/秒）、距離（セル）、やられ中（ms）」。距離 = `速さ² × sin(130°) ÷ 重力`（`sin(2 × 65°)`）。
- **距離は、速さの2乗に比例する**ため、`defense` の違いは、距離に大きく効く（例: 60 % で、`defense` 2 は 10.0 セル、`defense` 8 は 2.9 セル）。`defense` の違いが、観察しやすい一方、効きすぎないかは #25 で確認する。
- 場外（撃墜）に必要な距離は、ステージの寸法（#13）と、場外領域（#12）で決まる。必要な回数の見積もりは [combat-system.md](./combat-system.md) §11。

## 8. 計算の例

| 場面 | 計算 | 結果 |
|---|---|---|
| 標準が、標準の相手（0 %）に1回ヒット | ダメージ 12 % → (8 + 0.15 × 12) × 1.0 | 9.8 セル/秒（`vx` 4.1、`vy` 8.9）、やられ中 395 ms |
| 標準が、蓄積 88 % の標準の相手にヒット（ダメージ後 100 %） | 100 % → (8 + 15) × 1.0 | 23.0 セル/秒、やられ中 725 ms |
| 同じ状況で、相手の `defense` が 8 | 23.0 × 0.7 | 16.1 セル/秒 |
| 同じ状況で、相手の `defense` が 2 | 23.0 × 1.3 | 29.9 セル/秒 |

## 9. 例外・制約

| 場面 | 扱い |
|---|---|
| 蓄積ダメージが 999 % | そのまま式に使う。`HITSTUN_MAX` で、やられ中の長さを抑える |
| 攻撃側と相手が、同じ位置 | 攻撃した側の向きの前方へ吹き飛ばす |
| 相手が、壁・天井の近く | 壁・天井で止まる（§6）。跳ね返らない |
| 係数を調整した（#25） | 式と係数だけを変える。保存済みの設定は、影響を受けない |
