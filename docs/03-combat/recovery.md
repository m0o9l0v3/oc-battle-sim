# 復帰（recovery.md）

- 文書ID: CMB-RECOVERY
- バージョン: 0.1
- 状態: 草案（数値は暫定。調整は #25）
- 上位文書: [battle-rules.md](./battle-rules.md)
- 関連: [combat-system.md](./combat-system.md)、[knockback.md](./knockback.md)、[stat-system.md](../02-fighter/stat-system.md)

## 1. 概要

吹き飛ばされて、ステージの外に出たファイターが、ステージに戻る動き（**復帰**）の規則を定義する。空中での操作、空中ジャンプ、復帰の成功・失敗の定義、復帰できる蓄積ダメージの目安を扱う。

## 2. 目的

- ダメージが小さいうちは復帰でき、**大きくなると復帰できずに撃墜される**という流れにする（REQ-CMB-01）。ダメージの蓄積が、勝敗に効く。
- `jumpPower`、`speed`、`defense` が、復帰のしやすさに、違いとして現れる（REQ-EXP-02）。
- 復帰の成功・失敗を、Battle Report の指標の候補として記録する（[system-overview.md](../00-overview/system-overview.md) §6.3）。

## 3. 空中の動き

### 3.1 空中ジャンプ

| 項目 | 規則 |
|---|---|
| 回数 | 空中で、**2 回**まで（地面からのジャンプは、別に数えない） |
| 高さ | **地上のジャンプと同じ**（`jumpPower` で決まる。[stat-system.md](../02-fighter/stat-system.md) §6.2） |
| 動き | 上向きの速さを、ジャンプの初速にそろえる（落下中でも、上向きの速さを取り戻す）。横の速さは、変えない |
| 回数が戻るとき | **地面に着いたとき**、およびリスポーンしたとき |
| 戻らないとき | 吹き飛ばされたとき（やられたことでは、回数は戻らない） |
| できないとき | やられ中（吹き飛ばされて、操作できない間） |

- 空中ジャンプは、地面のジャンプと同じボタン。空中でボタンを押すと、回数が残っていれば、ジャンプする。

### 3.2 空中の横の動き

左右の入力に応じて、横の速さを、目標の速さに近づける。

| 項目 | 値 |
|---|---|
| 目標の速さ | 入力の向き × `moveSpeed`（`speed` で決まる。[stat-system.md](../02-fighter/stat-system.md) §6.2）。入力がないときは 0 |
| 加速（入力の向きへ） | **60 セル/秒²**（`AIR_ACCEL`） |
| 減速（入力がないとき） | **10 セル/秒²**（`AIR_DRAG`）で、0 に近づく |

- 吹き飛ばされた勢い（横の速さ）は、やられ中が終わったあと、入力の向きに応じて、**約 0.2〜0.4 秒**で、目標の速さに変わる（例: 逆向きに 7.5 セル/秒で飛んでいても、約 0.2 秒で、向きが変わる）。
- 空中でも、攻撃できる（復帰の動きには、効かない）。

### 3.3 補助がないこと

- ステージの端につかまる動作（ふち掴み）、瞬間移動、復帰専用の無敵は設けない。
- 復帰は、**空中ジャンプ（2回）と、空中の横の動き**だけで行う。

## 4. 場外の状態

ファイターが、次のどちらかに当てはまるとき、**場外にいる**とする。

| 条件 | 内容 |
|---|---|
| 左右の外 | 空中にいて、体の中心が、ステージの足場がある範囲（全足場の左端〜右端）の外側にある |
| 下 | 空中にいて、どの足場の上にもおらず、最も低い足場の上面より低い位置にある |

- 地面や足場の上にいるときは、場外ではない。
- 場外にいる間に、場外領域（撃墜の判定。[battle-rules.md](./battle-rules.md) §5.2）の外に出ると、撃墜。

## 5. 復帰の成功と失敗

| 結果 | 条件 |
|---|---|
| **復帰成功**（`recovery_success`） | 場外にいたファイターが、**撃墜されずに**、足場の上に着いた（地面の上に立った） |
| **復帰失敗**（`recovery_failure`） | 場外にいたファイターが、**撃墜された** |

- 1回の「場外にいる期間」（場外に出てから、足場に戻る、または撃墜されるまで）を、1回の復帰として数える。
- 場外にいる期間が、一瞬（例: 足場の縁で、少しはみ出しただけ）でも、数える。成功・失敗の区別が、指標として分かりやすいように、**場外にいた時間が 0.3 秒以上のもの**だけを、復帰として記録する（暫定）。
- 吹き飛ばされて、そのまま場外領域の外に出た（復帰を試みる前に撃墜された）場合も、**復帰失敗**として数える。

## 6. 能力値と復帰

| 能力値 | 復帰への効き方 |
|---|---|
| `jumpPower` | 空中ジャンプの高さ。高いほど、遠くから、戻れる |
| `speed` | 空中の横の速さの目標。速いほど、横に戻りやすい |
| `defense` | 吹き飛ぶ速さ（距離）。高いほど、遠くに飛ばされにくい（[knockback.md](./knockback.md) §3.1） |
| `attackPower` | 復帰には、直接は効かない（与えるダメージの量だけ） |

## 7. 復帰できる蓄積ダメージの目安

**ステージの端に立っているファイターが、外側に向けて吹き飛ばされた**場合（最も厳しい状況）に、最適な操作で、復帰できる蓄積ダメージ（ヒット後の値）の上限の目安。

### 7.1 前提

- 吹き飛ばしの角度は 65°（[knockback.md](./knockback.md) §4）。ステージの端から、外側へ飛ぶ。
- やられ中は、操作できない。終わった直後から、最適な向きに入力し、空中ジャンプ（2回）を、最適なタイミングで使う。
- 失敗の判定は、場外領域（左右 6 セル、下 6 セル、上 8 セル）に出たら。足場の上面に、上から戻れたら成功。
- 計算は、数値シミュレーション（1/60 秒の刻み）による。ステージの形（#13）で、結果は変わる。

### 7.2 結果（ステージの端、外向き。ヒット後の蓄積ダメージの上限）

| 能力値の配分（防御・ジャンプ・速さ） | 復帰できる上限の目安 |
|---|---|
| 標準（`defense` 5 / `jumpPower` 5 / `speed` 5） | **約 60 %** |
| `defense` 2（他は標準） | 約 33 % |
| `defense` 8 | 約 111 % |
| `jumpPower` 2 | 約 48 % |
| `jumpPower` 8 | 約 69 % |
| `speed` 2 | 約 36 % |
| `speed` 8 | 約 78 % |
| 配分 8/2/8/2（攻・防・跳・速）— 復帰しにくい配分の例 | 約 21 % |
| 配分 2/8/2/8 — 復帰しやすい配分の例 | 約 123 % |

- **標準では、ヒット後の蓄積ダメージが約 60 % まで（標準の1回 12 % で、約5回まで）は、端でも復帰できる。** それを超えると、端で受けた場合は、復帰できず撃墜される。
- 復帰しにくい配分（`defense` と `speed` が低い）では、**2回目のヒット（約 31 %）**で、端での復帰が難しくなる。**ステージの端の近くで、攻撃を受けないように戦う**ことが、効く配分になる。
- 復帰しやすい配分（`defense` と `speed` が高い）は、約 120 % まで、端でも復帰できる。ただし、攻撃は弱い（`attackPower` が低い）ので、撃墜を取りにくい。**トレードオフになる**。
- ステージの内側で受けた場合は、端までの距離があるため、同じ蓄積ダメージでも、復帰できる範囲が、広がる。

### 7.3 設計の確認（#25 で実施）

- 実際の対戦（人が操作）では、最適な操作はできない。上の上限は、**最も楽な場合の目安**。
- **1ヒットで、端で撃墜される配分が、ないこと。** 設定できる全 231 通りの配分で、復帰できる上限を数値で確かめた。**最小は約 18〜21 %**（`defense` 2、`jumpPower` 8、`speed` 2 など）、**最大は約 120 %**。1回のヒットのダメージの最大は 15.6 %（`attackPower` 8）なので、**どの配分でも、端で1回当たっただけでは、撃墜されない**。2回目のヒット（約 31 %）以降に、配分によって、復帰できなくなる。
- 能力値の違いが、観察できる程度に、大きいこと（`defense` 2 と 8 で、約 33 % と約 111 %）。

## 8. 例外・制約

| 場面 | 扱い |
|---|---|
| 空中ジャンプの回数が 0 のとき | ジャンプしても、何も起こらない |
| やられ中に、空中ジャンプの入力 | 効かない（回数も使わない） |
| 場外にいる間に、攻撃を受ける | 通常どおり、ダメージと吹き飛ばしを受ける |
| 足場の下から、足場に当たる | 当たった向きの速さを 0 にする。すり抜けない（床の仕様は #13、#22） |
| 場外にいる時間が 0.3 秒未満 | 復帰として、記録しない（§5） |
