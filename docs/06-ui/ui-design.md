## 1. 概要

画面全体のビジュアル方針、世界観と独自性の方針、共通コンポーネント、画面ごとのワイヤーフレーム（S01〜S12）を定義する。**既存作品と誤認されない、オリジナルの見た目**にする。

## 2. 目的

- 中学生が、短い説明で、迷わず使える画面にする（NFR-02）。
- 既存のゲームの素材・意匠・名称を使わない、独自の世界観にする（NFR-07、設計原則 8）。
- 1つの画面で決めることを、1つに絞る（設計原則 6）。
- 「数字を変えると動きが変わる」体験を、画面の中心に置く（設計原則 2）。

## 4. ビジュアル方針

| 項目 | 方針 |
|---|---|
| 全体の印象 | 明るく、わかりやすい。「ファイターを設計して、試す」実験室のような雰囲気（暫定の世界観: 「ファイターラボ」） |
| 言葉 | ひらがな中心のやさしい日本語。専門用語を使わない。文言は設定ファイルにまとめる |
| 1画面1目的 | 画面の上に、**いま何をする画面か**を、大きな見出しで示す（「ファイターを つくろう」など） |
| 進み具合 | 画面の上部に、**段階の表示**（つくる → ステージ → ためす → たいせん → ふりかえり）を、常に出す |
| 数字の見せ方 | 数字を、**大きく**、変えた結果が見える形で出す（能力値、ダメージ%、ストック、残り時間） |
| 色 | 色は、情報を伝える補助にとどめる。**色だけで意味を伝えない**（記号、文字、形を併用） |
| 動き | 控えめにする。点滅は、1秒に3回を超えない |
| 余白 | 広く取る。1画面の選択肢は、最大でも 8 つ程度 |

### 4.1 配色（役割。値は #36）

役割ごとの変数にまとめる（コードに色を直接書かない）。**明るい背景、濃い文字**を基本とする（教室のモニターで見やすい）。

| 役割 | 内容 |
|---|---|
| 背景 | 明るい（白に近い） |
| 文字 | 濃い（背景との対比 **4.5 : 1 以上**） |
| 主ボタン | 目立つ色（文字との対比 4.5 : 1 以上） |
| 補助ボタン | 控えめな色 |
| 成功 | 緑系 + ✓ の記号 |
| 注意・違反 | 赤系 + ！ または ✕ の記号 |
| 1P | 青系（+「1P」の文字） |
| 2P | 橙系（+「2P」の文字） |
| 対戦画面の背景 | やや暗めの落ち着いた色（ファイターとステージが目立つ） |

- 1P と 2P の色は、色覚の違いでも見分けられるよう、明るさも変える（[character-design.md](../02-fighter/character-design.md) §5.4）。

### 4.2 文字

| 項目 | 内容 |
|---|---|
| フォント | **OS に入っているフォント**を使う（例: Yu Gothic UI、Meiryo、Hiragino Sans、sans-serif）。外部のフォントを、読み込まない（会場の有線LANは、インターネットに出られないため。[event-connection.md](../08-architecture/event-connection.md)） |
| 見出し | 32 ピクセル以上 |
| 本文・ボタン | 24 ピクセル以上 |
| 数字（ダメージ%など） | 48 ピクセル以上（対戦中） |
| 行の長さ | 短く（1行に 20 文字程度まで） |

## 5. 独自性（既存作品と誤認されない）

### 5.1 方針

- **名称:** 画面・文書・コードで、既存作品の名前（「スマブラ」を含む）を使わない。アプリの名前は暫定「ファイターラボ」（#36 で確定）。
- **キャラクター・ステージ・UI:** 既存のゲームのキャラクター、ロゴ、効果音、BGM、アイコン、ステージの素材を使わない（NFR-07）。
- **レイアウト・意匠:** 既存作品の画面（キャラクター選択の並び、勝敗の演出、ダメージ表示の書体など）に、**似せない**。ダメージを「%」で示すこと、「ストック」という言葉は、一般的な言葉であり、使ってよい。ただし、書体、配色、枠の形は、独自にする。
- **世界観:** 「ファイターラボ」。ファイターを設計し、ステージで試す、実験室のイメージ。参加者の学校（日本航空大学校）の雰囲気と、矛盾しない、明るい色合い。
- **学校ロゴ:** 学校から許可を得た、公式提供のロゴを、**持ち帰り用QRの発行画面（S12）にだけ**表示する（許可の範囲: オープンキャンパスでの使用。[legacy-assessment.md](../08-architecture/legacy-assessment.md) §3.17）。ほかの画面には出さない。

### 5.2 素材

| 種類 | 方針 |
|---|---|
| 画像・アイコン | 自作、またはライセンスが明確なもの。出所を記録する（#50） |
| 効果音・BGM | **MVP では使わない**（任意）。使う場合は、自作、またはライセンスが明確なものに限る |
| フォント | OS のフォントのみ（§4.2） |
| `oc26-stage` の素材 | 学校ロゴ以外は、画面の素材を引き継がない（[legacy-assessment.md](../08-architecture/legacy-assessment.md) §3.11） |

### 5.3 確認

- #50（権利チェック）で、画面のすべて（名称、アイコン、配色、文言）を、確認する。
- チェックの観点: 既存作品の名前が、画面・文書にないこと、素材の出所が、すべて記録されていること。

## 6. 共通コンポーネント

| 部品 | 内容 |
|---|---|
| **ボタン**（主・補助） | 高さ 56 ピクセル以上。文字のラベルつき。押せないときは、見た目を変え、**理由を近くに表示**する |
| **数字ステッパー** | 「−」「＋」のボタンと、大きな数字。能力値の設定（S03）、2P の変更に使う。範囲の端で、押せなくなる |
| **残りポイント表示** | 能力値の画面の上部に、「あと ○ポイント」を、大きく出す |
| **選択肢のカード** | 見た目・プリセットなどの選択。選んだものは、枠と ✓ で示す |
| **メッセージ帯** | 成功（✓）、注意（！）、情報（i）。記号と文字つき |
| **段階の表示** | 画面上部の、5 つの段階（§4）。いまの段階を強調する |
| **HUD**（対戦中） | ダメージ%、ストック、残り時間、名前（§7.7） |
| **プレビュー** | ファイターを、大きく、Idle のアニメーションで見せる（S02、S03、S06、S12） |
| **ツールチップ** | 能力値の意味（「ジャンプの たかさが かわるよ」）を、マウスを乗せると、短く表示する |

- 確認のダイアログは、出さない（待たせない）。取り消しは「もどす」で行う。
- すべてのボタンは、マウスで操作できる。

## 7. ワイヤーフレーム

PC（16:9）の画面。`[ ]` はボタン、`( )` は選択、`▮` は数字。

### 7.1 S01 スタート

```text
┌──────────────────────────────────────────────┐
│                 ファイターラボ                  │
│     ファイターを つくって、ためして、なおそう！    │
│                                              │
│                   [ はじめる ]                │
│   （しんこうが はじまるまで おまちください）      │
│                          [ もちかえる ]（もちかえりの ときだけ） │
└──────────────────────────────────────────────┘
```

- 親機のフェーズが `PREPARE` の間、「はじめる」は押せない（理由を、近くに表示。[event-control.md](../01-experience/event-control.md) §6）。

### 7.2 S02 見た目を選ぶ

```text
┌ [つくる]→ステージ→ためす→たいせん→ふりかえり ───┐
│ ファイターを つくろう                               │
│  ┌──────────┐  からだ ( )( )( )( )              │
│  │  プレビュー │  かお   ( )( )( )( )( )( )        │
│  │ （うごく）  │  いろ   ( )( )( )( )( )( )( )( )   │
│  └──────────┘  かざり ( )( )( )( )( )( )(なし)   │
│  なまえ [        ]（10もじまで）  [ランダム]        │
│  ※ ほんとうの なまえは いれないでね（あだなに しよう）  │
│                                    [ つぎへ ]     │
└──────────────────────────────────────────────┘
```

- **名前の注意書き（必須）:** 名前の入力欄の**すぐ近く**に、「ほんとうの なまえは いれないでね（あだなに しよう）」を、常に表示する。名前は、持ち帰り用QRの URL に入り、共有されうるため（[character-design.md](../02-fighter/character-design.md) §9.3、[character-config.md](../02-fighter/character-config.md) §4）。ステージの名前の入力欄（S04）にも、同じ注意書きを出す。

### 7.0 共通: 「もどる」と「つぎへ」

- 画面の下に、**左に「もどる」、右に「つぎへ」**を置く（[user-flow.md](../01-experience/user-flow.md) §5.11 で、戻ってよい画面だけ。戻れない画面では、「もどる」を出さない）。
- 「もどる」は、**入力した内容を保持したまま**、前の画面へ戻る。**例外: S09 の「やめて もどる」は、編集した内容を、捨てる**（保持しない。再び S09 を開いたとき、「まえ」の値から始まる。§7.9）。
- 戻れる先: S03 → S02、S04 → S03、**S05 → S03 または S04（別々のボタン。§7.5）**、S06 → S05、**S09 → S08（第1戦の直後）または S11（再戦のあと）**。S01、S07、S08、S10 は、戻れない。S11 は、「もう一度 すうじを かえる」で、S09 へ進む。

#### 「もちかえる」ボタン（すべての画面で、親機の指示があるとき）

- 親機のフェーズが **`SHARING` または `BUFFER`** の間は、**S01〜S11 のすべての画面**の、**画面の上部（段階の表示の右。S01 は、見出しの右）**に、**「もちかえる」ボタン**を、常に表示する（[event-control.md](../01-experience/event-control.md) §5.3、[user-flow.md](../01-experience/user-flow.md) §6.1.2）。押すと、S12 に進む。
- 対戦中（S07、S10）は、対戦を中断しない。**対戦が終わったあと**に、押せる（それまでは、押せない理由「たいせんが おわるまで まってね」を表示）。
- `SHARING` の間は、ほかの操作（設定の変更など）は押せなくなる。「もちかえる」は、常に押せる。
- これにより、S01〜S11 のどの画面にいた参加者も、持ち帰り用QR（S12）に、必ず行ける。**S01 にいる参加者**（まだ始めていない）も、押すと、標準の設定の QR（§7.11.1）が出る。S01 の「はじめる」は、`SHARING` の間は押せないため、この「もちかえる」が、S01 から先へ進む、唯一の操作になる。

[stage-editor.md](../04-stage/stage-editor.md) §4 のとおり（プリセットの一覧、ステージの編集画面、道具、検証の結果、「つぎへ」）。

### 7.5 S05 試しに動かす

```text
┌ ステージを ためそう ────────────────────────────┐
│  ┌──────── ステージ（ひとりで うごかす）────────┐    │
│  │            ファイター                      │    │
│  └─────────────────────────────────────┘    │
│  うごかしかた: 1P  A D  ジャンプ W  こうげき F      │
│  [ すうじを なおす ]  [ ステージを なおす ]  [ たいせんへ ] │
└──────────────────────────────────────────────┘
```

- 「すうじを なおす」→ S03（能力値）へ。「ステージを なおす」→ S04（ステージ）へ。どちらも、入力した内容を保持して戻る。戻ったあと、「つぎへ」で、S05 に進める（[user-flow.md](../01-experience/user-flow.md) §5.5、§5.11）。

### 7.6 S06 対戦の準備

```text
┌ たいせんの じゅんび ───────────────────────────┐
│  1P（あなた）                2P（あいて）          │
│  ┌─────┐                 ┌─────┐              │
│  │ 絵    │ なまえ          │ 絵    │ なまえ         │
│  └─────┘ すうじ ▮▮▮▮     └─────┘ すうじ ▮▮▮▮    │
│                              [あいての すうじを かえる] │
│  キーを ためそう:  1P [A][D][W][F]                  │
│     2P [4][6][8][5]  または  [←][→][↑][/]        │
│  （おした キーが ひかるよ）                           │
│  [ もどる ]                       [ たいせん スタート ] │
└──────────────────────────────────────────────┘
```

- キーの確認は、[pc-ui.md](./pc-ui.md) §7。**2P は、テンキーの配置と、矢印キーの配置の、両方**を並べて表示する（テンキーがないPCでも、見つけられる。[pc-ui.md](./pc-ui.md) §4.2）。どちらのキーを押しても、該当の表示が光る。

#### 7.6.1 あいての すうじを かえる（2P の能力値の変更）

「あいての すうじを かえる」を押すと、**同じ S06 の中で、2P の欄が開く**（別の画面へ移らない）。

```text
┌ たいせんの じゅんび ───────────────────────────┐
│  2P（あいて）の すうじ              あと ▮ポイント     │
│   こうげき力   [−] ▮ [＋]    ダメージ 100%         │
│   ふっとばされにくさ [−] ▮ [＋]  ふっとび 100%       │
│   ジャンプ力   [−] ▮ [＋]    たかさ 100%          │
│   いどうのはやさ [−] ▮ [＋]   はやさ 100%          │
│   （ぜんぶで 20ポイント。2〜8の あいだで えらぼう）    │
│   [ひょうじゅんに もどす]             [ きまり ]       │
└──────────────────────────────────────────────┘
```

| 項目 | 内容 |
|---|---|
| 開き方 | 「あいての すうじを かえる」を押す。2P の欄（能力値のステッパー4つ、残りポイント、標準比）が、S06 の中で開く（1P の欄は、そのまま見える） |
| 内容 | S03 と同じ部品（数字ステッパー、残りポイント、標準との比較）。**変えられるのは、能力値だけ**（外観は変えない。[character-design.md](../02-fighter/character-design.md) §5.3） |
| 検証 | 範囲 2〜8、合計 20（[stat-system.md](../02-fighter/stat-system.md) §5.1）。合計が 20 でないと、「きまり」は押せない（理由を、近くに表示: 「あと ○ポイント つかおう」）。**開いている間は、「たいせん スタート」も押せない**（理由を表示） |
| 閉じ方 | 「きまり」を押すと、欄が閉じ、S06 に戻る。2P の数字の表示が、新しい値になる。「ひょうじゅんに もどす」で、5/5/5/5 に戻せる |
| 初期値 | 標準設定（5/5/5/5）。何も変えず、そのまま「たいせん スタート」を押してもよい（欄を、開かなくてよい） |
| 保持 | 変えた値は、以降の戦（S10）の初期値（S09 の「まえ」の値）になる（[user-flow.md](../01-experience/user-flow.md) §5.9） |

### 7.7 S07・S10 対戦（HUD）

```text
┌──────────────────────────────────────────────────┐
│ 1P なまえ  ●●●  34%           残り 1:12           2P なまえ  ●●○  61% │
│                                                                    │
│                     （ステージ、ファイター、場外領域まで表示）          │
│                                                                    │
└──────────────────────────────────────────────────┘
```

| 要素 | 内容 |
|---|---|
| ダメージ % | 名前の隣に、大きく。ヒットで、数字が増え、短く強調する |
| ストック | ●（残り）と ○（失った）で表す（色だけに頼らない） |
| 残り時間 | 分:秒。10 秒を切ったら、強調する（点滅は、1秒に3回まで） |
| 開始 | 「3・2・1・スタート」を、画面の中央に大きく |
| 終了 | 勝敗を、大きく表示（「1P の かち」「ひきわけ」） |

- 場外領域まで表示するため、ステージは、画面の一部になる（拡大率の決め方は #20）。

### 7.9 S09 設定を変えて作り直す

```text
┌ すうじを かえよう ────────────────────────────┐
│  1P（あなた）   あと ▮ポイント      2P（あいて）  あと ▮ポイント │
│  こうげき力   まえ ▮ → [−] ▮ [＋]   こうげき力  まえ ▮ → [−] ▮ [＋] │
│  ふっとばされにくさ …                ふっとばされにくさ …          │
│  ジャンプ力   …                    ジャンプ力   …              │
│  いどうのはやさ …                  いどうのはやさ …            │
│  （かえた すうじは めだつよ）                              │
│  [1P を ひょうじゅんに]               [2P を ひょうじゅんに] │
│  「1P の すうじを ひとつは かえよう」                       │
│  [ やめて もどる ]                [ もういちど たいせん ]   │
└──────────────────────────────────────────────┘
```

- **1P と 2P の両方**の能力値を、1つの画面に、左右に並べて、変えられる（[user-flow.md](../01-experience/user-flow.md) §5.9）。それぞれに、残りポイントと、数字ステッパーがある。
- 各行に、**直前の値（まえ）**と、いまの値を並べる。変えた数字を強調する（変えた数字に、記号「◆」もつける。色だけに頼らない）。
- 再戦に進める条件は、**1P の能力値が、直前から1つ以上変わっていること**と、**1P・2P ともに、20 ポイントを使い切っていること**。2P だけを変えても、「もういちど たいせん」は押せない（理由を、近くに表示: 「1P の すうじを ひとつは かえよう」）。
- 2P の欄は、2P を操作する人が、そのまま触れる位置にある（同じ画面）。変えたくないときは、触らなくてよい（直前の値のまま）。
- **「ひょうじゅんに もどす」は、列ごとに、別々のボタン**（「1P を ひょうじゅんに」「2P を ひょうじゅんに」）。**押した側の列だけ**を、標準設定（5/5/5/5）に戻す。もう一方の列は、変わらない（2人が、別々に編集するため。1P の変更の判定に、2P の操作が影響しない）。
- 再戦に進める条件の「1P の能力値が、直前から1つ以上変わっている」は、**いまの1Pの値と、「まえ」の値を比べて**判定する（標準に戻した結果、「まえ」と同じ値になれば、変わっていないことになる）。
- 「やめて もどる」: 編集した内容を**捨てて**、前の結果の画面へ戻る（第1戦の直後は S08、再戦のあとは S11）。マウスだけで操作できる（[user-flow.md](../01-experience/user-flow.md) §5.11）。
- **S09 の初期値は、直前の戦で使った、1P・2P それぞれの能力値**（「まえ」の値）。2P を S06 で変えていれば、その値から始まる（標準設定にリセットしない）。**標準設定が初期値になるのは、最初の S06 の2P だけ**（[user-flow.md](../01-experience/user-flow.md) §5.6）。
- S03（最初の能力値の決定）は、1P だけ。S09 は、1P と 2P の両方。

### 7.10 S11 結果の比較

```text
┌ くらべてみよう ─────────────────────────────┐
│ くらべる:  [ 第 ▮ 戦 ▼ ] と [ 第 ▮ 戦 ▼ ]   （えらべるよ） │
│ 1P の すうじ   第 ▮ 戦    第 ▮ 戦（いま）   かわったところ  │
│ こうげき力        5           7            ◆ ＋2     │
│ ふっとばされにくさ    5           3            ◆ −2     │
│ ジャンプ力        5           5              0       │
│ いどうのはやさ     5           5              0       │
│ ─ けっか ─                                          │
│ ダメージ（あたえた）  ▮           ▮            ▮         │
│ ふっとばした回数     ▮           ▮            ▮         │
│  [ もう一度 すうじを かえる ]          [ おわる ]       │
└──────────────────────────────────────────────┘
```

- **1P の能力値は、4つすべて**（こうげき力、ふっとばされにくさ、ジャンプ力、いどうのはやさ）を表示する。再戦は、1P の能力値が1つ以上変わっている（[user-flow.md](../01-experience/user-flow.md) §5.9）ので、**どの能力値が変わっても、変更が見える**。変わった行は、「◆」と、強調で示す（色だけに頼らない）。
- 2P の能力値は、「2P の すうじ」の欄（折りたたみ、または並べて）で見られる（変わっていれば、「◆」）。
- **列の見出しは、実際の戦の番号**（第 2 戦と第 3 戦、など）。「1かいせん」「2かいせん」のように、固定にしない。再戦は何度でもできるため、戦は、第 1 戦、第 2 戦、第 3 戦… と増える（[user-flow.md](../01-experience/user-flow.md) §5.10）。
- **初めに比べる2つ（既定）:** **直前の戦**（左）と、**いま終わった戦**（右、「いま」）。第2戦が終わったときは、第1戦と第2戦。
- 上の「くらべる」の選択（第 ▮ 戦 ▼）で、**比べる2つの戦を、選び直せる**（保存されている戦のうちから、2つ）。たとえば、第1戦と第4戦。比べる基準の最終的な仕様は #16。
- 「かわったところ」は、選んだ2つの戦の差。
- 変わった数字を強調する。結果の差も、数字で示す。

### 7.11 S12 おわり

```text
┌ おつかれさま！ ────────────────────────────┐
│ [学校のロゴ]    きょうの たいけんを おうちで つづけよう  │
│   ┌──────┐    ・ QRコードを スマホで よみとる        │
│   │ QR   │    ・ または この URL を メモしよう         │
│   └──────┘      https://…（もちかえり URL）          │
│  「すうじを かえると、うごきが かわったね！」             │
│  （スタッフが リセットするまで そのまま）                 │
└──────────────────────────────────────────────┘
```

- QR と URL の文字を、常に表示する（[user-flow.md](../01-experience/user-flow.md) §5.13）。

#### 7.11.1 QR に入れる設定（未完成の画面から、S12 に来たとき）

「もちかえる」ボタン（§7.0）で、S02・S03・S04・S06 など、**途中の画面から S12 に来る**ことがある。QR には、**必ず、検証を通る、完成した設定**を入れる。

| 項目 | QR に入れる値 |
|---|---|
| 見た目・名前 | 編集中の値が有効なら、その値。有効でない、またはまだ確定していないときは、**直前に確定した値**。一度も確定していなければ、**標準の見た目**（[character-design.md](../02-fighter/character-design.md) §5.3 の初期値）と、デフォルト名 |
| 能力値 | **常に 1P の能力値**。1P の編集中の合計が 20 で、範囲内なら、その値。そうでなければ、**1P の、直前に確定した値**（直前の戦の値など）。一度も確定していなければ、**標準設定（5/5/5/5）**。**2P（あいて）の能力値は、QR に入れない**（S06 の2P の欄や S09 の2P の列が開いていても、それは、QR に影響しない） |
| ステージ | 編集中のステージが、検証を通れば、その値。通らなければ、**直前に確定したステージ**。一度も確定していなければ、**標準のプリセット** |

- 持ち帰る設定は、**参加者（1P）のファイター**。見た目・名前・能力値のすべてが、1P のもの（[user-flow.md](../01-experience/user-flow.md) §5.13）。2P の設定が、1P の見た目・名前と、混ざることはない。
- QR を作る前に、`validateConfig` と `validateStage`（[character-config.md](../02-fighter/character-config.md) §5、[validation.md](../04-stage/validation.md) §7）で、**通ることを確認**する。通らないときは、上の「直前に確定した値」「標準の値」にする。したがって、QR が、作れない・無効になることは、ない。
- 入れなかった編集内容は、QR に入らない（持ち帰った先では、確定した値で始まる）。S12 の画面に、「つくりかけの ぶぶんは、いまの 設定で もちかえるよ」と、短く表示する（途中で来た場合だけ）。

## 8. ファイター・ステージの表示

- ファイターの表示は、[character-design.md](../02-fighter/character-design.md) §7 の品質基準に従う。
- ステージのブロックは、見分けやすい色と、縁取りをつける（背景との対比を確保）。
- 1P と 2P の頭上に、「1P」「2P」の目印（[character-design.md](../02-fighter/character-design.md) §5.4）。

## 9. 画面の大きさ

- 基準は **1280 × 720（16:9）**。大きな画面では、拡大して表示する（余白で、縦横比を保つ）。
- 文字の大きさは、画面の拡大に合わせて変える（読みやすさを保つ）。
- スクロールが必要な画面は、作らない（1画面に収める）。

## 10. 安定運用の制約

| 項目 | 方針 |
|---|---|
| 外部の資源 | **フォント・画像・スクリプトを、外部から読み込まない**（会場の有線LANは、インターネットに出られない） |
| 読み込み | 画像は、アプリに同梱する（親機のローカルサーバーから配信される） |
| 動き | 軽い（60 FPS を妨げない。NFR-03） |
| 文言 | 設定ファイルにまとめ、調整だけで直せる |

## 11. アクセシビリティ

- 色だけに頼らない（記号、枠、文字を併用）。
- 文字の対比 4.5 : 1 以上。
- 点滅は 1 秒に 3 回まで。
- ボタンのラベルは、文字（アイコンだけにしない）。
