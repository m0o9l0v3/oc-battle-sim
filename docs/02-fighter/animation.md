# アニメーション仕様（animation.md）

- 文書ID: FTR-ANIM
- バージョン: 0.1
- 状態: 草案（数値は暫定。実機での見た目の調整は #29）
- 上位文書: [system-overview.md](../00-overview/system-overview.md)（§5.3、REQ-FTR-04）
- 関連: [character-design.md](./character-design.md)、[stat-system.md](./stat-system.md)、`combat-system.md`（#11）

## 1. 概要

ファイターの Idle / Run / Jump / Fall / Attack / Hit / KO の7状態を、**少数のパーツの移動・回転・拡大縮小**で表現する方式を定義する。7つのクリップ（動きの定義）は、**体型・顔・色・アクセサリーに関係なく、全員共通**で使う。

## 2. 目的

- 少数の共通のクリップで、すべてのファイターを動かす（固有モーションを大量に作らない。設計原則 7）。
- ゲームの状態（地面にいる、空中にいる、攻撃中、やられ中など）から、見るべき動きが一意に決まるようにする。
- 見た目だけの動きで、当たり判定や物理を変えない（REQ-FTR-05）。

## 3. Requirements

| ID | 要求 | 本書での具体化 |
|---|---|---|
| REQ-FTR-04 | 少数の再利用パーツの移動・回転・拡大縮小で簡易アニメーション | §4、§5 |
| REQ-FTR-05 | 見た目の変化は当たり判定を変えない | §9 |
| NFR-03 | 対戦中の目標は60 FPS | §8（計算量が小さい） |
| NFR-05 | オリジナルのキャラクターとして認識できる品質 | §10 |

## 4. パーツと座標

### 4.1 動かすパーツ

[character-design.md](./character-design.md) §4 のパーツを動かす。

| 名前 | パーツ | 回転の中心（関節） |
|---|---|---|
| `root` | ファイター全体 | 足元の中心（移動・拡大縮小）。回転は、体の中心 |
| `torso` | 胴体 | 腰 |
| `head` | 頭 | 首の付け根 |
| `armF`、`armB` | 手前の腕、奥の腕 | 肩 |
| `legF`、`legB` | 手前の脚、奥の脚 | 股の付け根 |

- 顔（face）は、動かさず、**表情の絵を切り替える**（`normal` / `attack` / `hit` / `ko`）。`normal` は、選んだ顔の絵。それ以外は全員共通の絵（[character-design.md](./character-design.md) §4.3）。
- アクセサリーは、**自分では動かさない**。付ける場所（スロット）の親のパーツに追従する（頭・顔のスロットは `head`、首・背中のスロットは `torso`）。アクセサリーごとのクリップは作らない。

### 4.2 単位と向き

| 項目 | 規則 |
|---|---|
| 長さ | **身長 H の百分率（%H）**。H は、見た目の高さ（頭〜足）。体型が違っても、同じ数値で動かす |
| 角度 | 度。**0° は真下**（腕・脚は真下に垂れる）。**正の値は、体の前方（向いている側）へ振る**。上へ上げるときは、前方へ約 +150° |
| 胴体・頭の傾き | 0° は直立。正の値は、**前傾**（向いている側へ倒れる） |
| `root` の回転 | 正の値は、前転（向いている側へ回る） |
| 拡大縮小 | 1.0 が標準。`sx`（横）、`sy`（縦）。足元を基準に伸縮する |
| `dy` | **正の値は、上方向**。`dx` は、**正の値が前方** |
| 向き | 右向きで定義する。左向きは、`root` を左右反転する（`sx` の符号）。向きの切り替えは、即時 |

### 4.3 ポーズとクリップ

```ts
type PartPose = { dx?: number; dy?: number; rot?: number; sx?: number; sy?: number }

type Pose = {
  root: PartPose
  torso: PartPose
  head: PartPose
  armF: PartPose
  armB: PartPose
  legF: PartPose
  legB: PartPose
  face: 'normal' | 'attack' | 'hit' | 'ko'
}

type Ease = 'linear' | 'easeOut' | 'easeInOut'

type Keyframe = {
  t: number // ミリ秒（クリップの先頭から）
  pose: Partial<Pose> // 指定しない部分は、前のキーフレームの値を引き継ぐ
  ease?: Ease // 直前のキーフレームから、このキーフレームへの補間
}

type Clip = {
  state: 'idle' | 'run' | 'jump' | 'fall' | 'attack' | 'hit' | 'ko'
  loop: boolean // true: 繰り返す。false: 最後のポーズで止まる
  duration: number // ミリ秒
  affects: (keyof Pose)[] // このクリップが動かすパーツ（§6.2）
  keyframes: Keyframe[]
}
```

- クリップは、データ（JSON）として持つ。コードに数値を直接書かない（調整を、設定の書き換えで済ませる）。
- 補間は、キーフレームの間を、`ease` に従って、数値ごとに行う。

### 4.4 基準のポーズ（Neutral）

全クリップの基準となる、立っているポーズ。

| 部位 | 値 |
|---|---|
| `root` | `dx 0`、`dy 0`、`rot 0`、`sx 1`、`sy 1` |
| `torso` / `head` | `rot 0` |
| `armF` / `armB` | `rot +4` / `rot −4`（少し開いて垂れる） |
| `legF` / `legB` | `rot +3` / `rot −3` |
| `face` | `normal` |

## 5. 7つのクリップ

数値は暫定。**単位は §4.2**。表に書かない部位・値は、Neutral（または前のキーフレーム）のまま。

### 5.1 Idle（待機）

- 繰り返し、1200 ms、`easeInOut`。呼吸のように、わずかに動く。

| t (ms) | `root.sy` | `torso.rot` | `head.dy` | `armF.rot` | `armB.rot` |
|---|---|---|---|---|---|
| 0 | 1.00 | 0 | 0 | +4 | −4 |
| 600 | 1.02 | +1 | +1 | +7 | −7 |
| 1200 | 1.00 | 0 | 0 | +4 | −4 |

### 5.2 Run（走り）

- 繰り返し、**600 ms**（標準の移動速度のとき）、`linear`。
- **再生の速さは、移動速度に比例させる:** 再生倍率 = 実際の移動速度 ÷ 標準の移動速度（`BASE_SPEED`。[stat-system.md](./stat-system.md) §6.1）。範囲は 0.6〜1.6 に制限する。
  - `speed` を変えると、走る足の動きの速さが変わる。能力値の違いが、**動きで**観察できる（外観は変えない。[character-design.md](./character-design.md) §6）。
  - 能力値ごとのクリップは作らない。同じクリップを、速さだけ変えて再生する。

| t (ms) | `root.dy` | `torso.rot` | `head.rot` | `armF.rot` | `armB.rot` | `legF.rot` | `legB.rot` |
|---|---|---|---|---|---|---|---|
| 0 | 0 | +8 | −4 | −40 | +40 | +40 | −40 |
| 150 | +3 | +8 | −4 | 0 | 0 | 0 | +20 |
| 300 | 0 | +8 | −4 | +40 | −40 | −40 | +40 |
| 450 | +3 | +8 | −4 | 0 | 0 | +20 | 0 |
| 600 | 0 | +8 | −4 | −40 | +40 | +40 | −40 |

### 5.3 Jump（上昇）

- 繰り返さない。**160 ms** で、構えから伸びの姿勢になり、その姿勢を保つ。`easeOut`。落下に入ると Fall になる（§6）。

| t (ms) | `root.sx` | `root.sy` | `torso.rot` | `armF.rot` | `armB.rot` | `legF.rot` | `legB.rot` |
|---|---|---|---|---|---|---|---|
| 0 | 1.06 | 0.92 | +10 | −30 | −30 | +25 | +15 |
| 60 | 0.95 | 1.08 | −3 | +140 | +120 | +30 | −15 |
| 160 | 1.00 | 1.03 | −3 | +140 | +120 | +30 | −15 |

- 0〜60 ms が、踏み切りの溜め（つぶれ）。60 ms 以降が、伸び。位置の上昇は、物理（#22）が行い、アニメーションは、`root.dy` を動かさない。

### 5.4 Fall（落下）

- 繰り返し、500 ms、`easeInOut`。腕を上げ、脚を開く。

| t (ms) | `root.sy` | `torso.rot` | `armF.rot` | `armB.rot` | `legF.rot` | `legB.rot` |
|---|---|---|---|---|---|---|
| 0 | 1.02 | −3 | +150 | +135 | +20 | −20 |
| 250 | 1.04 | −3 | +165 | +150 | +28 | −26 |
| 500 | 1.02 | −3 | +150 | +135 | +20 | −20 |

### 5.5 Attack（攻撃）

- 繰り返さない。**長さは、攻撃のフレーム（発生・持続・硬直。#11）に合わせる**。キーフレームの時刻を、固定の値でなく、攻撃の3つの区間の割合で決める。
- 3つの区間: **発生（startup）**、**持続（active）**、**硬直（recovery）**。

| 位置 | `root.dx` | `torso.rot` | `head.rot` | `armF.rot` | `armB.rot` | `face` |
|---|---|---|---|---|---|---|
| 発生の開始 | 0 | 0 | 0 | +4 | −4 | `normal` |
| 発生の終わり（構え） | −2 | −10 | −4 | −70 | +20 | `attack` |
| 持続の開始（打撃） | +5 | +14 | +4 | +95 | −25 | `attack` |
| 持続の終わり | +5 | +14 | +4 | +95 | −25 | `attack` |
| 硬直の終わり | 0 | 0 | 0 | +4 | −4 | `normal` |

- 補間は、発生: `easeInOut`、持続の開始: `linear`（打撃は速く）、硬直: `easeOut`。
- `affects` は、`root.dx`、`torso`、`head`、`armF`、`armB`、`face` だけ。**脚は動かさず、今の移動の動き（Idle / Run / Jump / Fall）のまま**にする（§6.2）。これにより、空中の攻撃も、地上の攻撃も、1つのクリップで表せる。

### 5.6 Hit（やられ）

- 繰り返さない。**やられ中（動けない時間。#11）の間**、のけぞった姿勢を保つ。最初の 60 ms でのけぞり、最後の 100 ms で戻る。最短 200 ms。

| 区間 | `root.dx` | `root.sx` | `root.sy` | `torso.rot` | `head.rot` | `armF.rot` | `armB.rot` | `legF.rot` | `legB.rot` | `face` |
|---|---|---|---|---|---|---|---|---|---|---|
| 0 ms | 0 | 1.00 | 1.00 | 0 | 0 | +4 | −4 | +3 | −3 | `hit` |
| 60 ms（のけぞり） | −4 | 0.94 | 1.05 | −22 | −28 | −60 | −45 | +18 | −12 | `hit` |
| 終わりの 100 ms 前 | −4 | 0.94 | 1.05 | −22 | −28 | −60 | −45 | +18 | −12 | `hit` |
| 終わり | 0 | 1.00 | 1.00 | 0 | 0 | +4 | −4 | +3 | −3 | `normal` |

- `easeOut`。やられ中の長さに応じて、中間を保つ時間だけを伸ばす。

### 5.7 KO（撃墜）

- 繰り返さない。**900 ms**。吹き飛びながら、回転し、小さくなる。

| t (ms) | `root.rot` | `root.sx` / `root.sy` | `torso.rot` | `armF.rot` | `armB.rot` | `legF.rot` | `legB.rot` | `face` |
|---|---|---|---|---|---|---|---|---|
| 0 | 0 | 1.00 | −15 | +60 | +60 | +40 | −30 | `ko` |
| 900 | +720 | 0.60 | −15 | +60 | +60 | +40 | −30 | `ko` |

- `linear`。回転は、体の中心を軸にする。最後のポーズで止まり、リスポーン（#12）で消える。

### 5.8 着地（クリップでなく、重ねる動き）

- 7状態とは別に、**着地の瞬間**だけ、`root` を一時的につぶす（加算）。独立した状態にしない。

| t (ms) | `root.sx` | `root.sy` |
|---|---|---|
| 0 | 1.08 | 0.90 |
| 80 | 1.00 | 1.00 |

- 条件: 空中から地面に着いたときの落下の速さが、**6 セル/秒以上**のとき（短い着地では出さない）。`easeOut`。

## 6. 状態の選び方

### 6.1 ゲーム状態

アニメーションは、1ステップごとに、ファイターの状態の**スナップショット**から決める。

```ts
type FighterSnapshot = {
  onGround: boolean
  vx: number // 横の速度（セル/秒）
  vy: number // 縦の速度（セル/秒。正が下）
  moveInput: -1 | 0 | 1 // 左右の入力
  attackPhase: null | 'startup' | 'active' | 'recovery' // 攻撃中のみ
  attackProgress: number // 攻撃全体の進み（0〜1）
  hitstunRemaining: number // やられ中の残り時間（ms）。0 ならやられ中でない
  ko: boolean // 撃墜されている
}
```

### 6.2 状態の優先順位と、動かす部位

上から順に、最初に当てはまるものを選ぶ。

| 優先 | 条件 | 状態 | 動かす部位 |
|---|---|---|---|
| 1 | `ko` | **KO** | すべて |
| 2 | `hitstunRemaining > 0` | **Hit** | すべて（攻撃より優先。攻撃中でも、やられたら攻撃の動きは打ち切る） |
| 3 | `attackPhase` が `null` でない | **Attack** | 上半身と `root.dx`。脚は、下の「移動の動き」に従う |
| 4 | `!onGround` かつ `vy < 0` | **Jump** | すべて |
| 5 | `!onGround` かつ `vy ≥ 0` | **Fall** | すべて |
| 6 | `onGround` かつ（`moveInput ≠ 0` または `|vx| > 0.2` セル/秒） | **Run** | すべて |
| 7 | それ以外 | **Idle** | すべて |

- 優先順位の 4〜7 が「移動の動き」。**攻撃（優先 3）は、上半身だけを上書き**し、脚は、移動の動き（Jump / Fall / Run / Idle）のままにする。
- 同じ入力から、同じ状態が選ばれる（決定的）。乱数を使わない。

### 6.3 ゲームの状態との対応

| ゲームの状態 | 状態 |
|---|---|
| 立っている、入力なし | Idle |
| 左右の入力、または動いている（地面） | Run |
| ジャンプして上昇中 | Jump |
| 下降中（足場から落ちた場合も） | Fall |
| 攻撃（発生・持続・硬直） | Attack（上半身） |
| 攻撃を受けて、動けない時間 | Hit |
| 場外で撃墜 | KO |
| リスポーン後 | Idle から（リスポーンの演出は #12 で、点滅などの別の効果として扱う） |

### 6.4 切り替え（つなぎ）

| 切り替え | つなぎの時間 |
|---|---|
| 移動の動きどうし（Idle / Run / Jump / Fall） | 60 ms でなめらかに補間する |
| Attack の開始・終了 | 30 ms |
| Hit に入る | 20 ms（すぐにのけぞる） |
| KO に入る | 0 ms（即時） |
| Hit・KO から戻る | 60 ms |

- 最短の保持時間: Hit は 200 ms。短時間に状態が行き来して、ちらつかないようにする。

## 7. 時間の扱い

- アニメーションの時間は、**ゲームのステップ（固定の更新。60 Hz。#20）で進める**。壁の時計は使わない。物理や攻撃のフレームと、同じ時間でそろい、動きが再現できる。
- ミリ秒を、ステップ数に換算する（1ステップ ≈ 16.7 ms）。
- 画面の更新が、ステップより細かいときは、直前と今のポーズの間を補間して描く（見た目をなめらかにするだけで、状態は変えない）。
- 一時停止・スロー（デバッグ）のときも、ゲームのステップに合わせて動く。

## 8. 実装の方針

- 状態の選択（`selectState`）、クリップの再生（`sampleClip(clip, t)`）、ポーズの合成（`composePose`）は、描画から独立した純粋な関数にして、**ユニットテストできる**ようにする（#29）。
- 1ファイターあたりの、1ステップの計算は、7つのパーツのポーズの補間だけで、非常に小さい。20体が同時にいても、60 FPS に影響しない（NFR-03）。
- クリップのデータは、TypeScript の型で検証する。キーフレームの順序、`duration`、`affects` を、起動時に確認する。

## 9. 当たり判定との関係

- アニメーションは、**見た目だけ**。当たり判定、物理の位置、速度、攻撃の判定範囲を、変えない（REQ-FTR-05）。
- 攻撃の判定範囲は、攻撃の仕様（#11）で決まり、攻撃の動き（腕の伸び）と、**見た目が大きくずれない**ように、#29 で確認する。
- 見た目が、当たり判定の枠から外れる大きさは、**±15% 以内**（[character-design.md](./character-design.md) §7.3）。KO（撃墜の演出）は、当たり判定がなく、対象外。
- 打撃の `root.dx +5%H`（前に踏み込む）は、見た目だけで、位置は変えない。

## 10. 品質と確認

- 7つの状態すべてで、パーツの継ぎ目が目立たない（[character-design.md](./character-design.md) §7.2）。
- 体型4種すべてで、同じクリップが、不自然にならない。関節の位置が、体型ごとに違っても、角度と %H の動きは共通。体型ごとに、見た目で不自然な場合は、**クリップを分けず**、関節の位置の調整で直す。
- Run の速さ（`speed` 2 と 8）で、走る足の動きが、不自然でない（再生倍率 0.7〜1.3）。
- アクセサリー（頭・顔・首・背中）が、追従して、パーツの陰に消えたり、浮いたりしない。

## 11. 例外・制約

| 場面 | 扱い |
|---|---|
| 攻撃中に、地面から離れた | Attack は上半身だけを動かす。脚は、Jump / Fall になる |
| 攻撃中に、やられた | Hit に切り替える。攻撃の動きは、そこで打ち切る |
| 同じステップで、複数の条件が成立 | §6.2 の優先順位に従う |
| 左右の向きが変わった | 即時に反転する。向き替えのクリップは作らない |
| クリップのデータが不正 | 起動時の検証で検出する。実行中は、Neutral のポーズにフォールバックする |

## 12. Acceptance Criteria

- [ ] 7つの状態それぞれの、パーツの変形（キーフレーム）が定義されている（§5）
- [ ] 状態の選び方（優先順位）が、ゲームの状態と対応づけられている（§6）
- [ ] 固有モーションを作らない（全員共通のクリップ、体型・アクセサリーごとのクリップなし）方針が示されている（§1、§4.1、§10）
- [ ] 移動速度に応じた再生の速さで、能力値の違いを、動きで示している（§5.2）
- [ ] アニメーションが、当たり判定と物理を変えないことが明記されている（§9）
- [ ] 状態の選択が、決定的で、ユニットテストできる形で書かれている（§6、§8）
